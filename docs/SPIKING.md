# Spiking neural networks

MultiNEAT2 supports stateful, event-driven spiking phenotypes alongside its
existing rate networks. A phenotype may mix rate and spiking neurons; every
connection can carry analog activation or delayed spikes according to its
source.

## Activation modes

Four evolvable activation modes are available:

| Activation | State update |
| --- | --- |
| `SPIKING_LIF` | Leaky integrate-and-fire with configurable rest, reset, threshold, resistance, membrane time constant, and absolute refractory period |
| `SPIKING_ADAPTIVE_LIF` | LIF plus an exponentially decaying, spike-triggered adaptation current |
| `SPIKING_IZHIKEVICH` | Canonical two-state Izhikevich dynamics with evolvable `a`, `b`, `c`, and `d` |
| `MCCULLOCH_PITTS` | Binary threshold firing with an optional absolute inhibitory veto and refractory timing |

The synchronous solver advances all neurons with an explicit time step. A
spike generated by a non-input neuron is transmitted on the next solver step.
Each synapse then applies its physical delay. This makes recurrent execution
deterministic and independent of connection-vector order.

LIF uses:

```text
dv/dt = (v_rest - v + R * I - adaptation) / tau_membrane
```

Adaptive LIF uses:

```text
dadaptation/dt = -adaptation / tau_adaptation
adaptation <- adaptation + adaptation_increment  after a spike
```

Izhikevich uses its standard millisecond parameterization:

```text
dv/dt = 0.04 v² + 5 v + 140 - u + I
du/dt = a (b v - u)
```

Crossing the threshold emits a one-step spike, updates the filtered rate
trace, records an event when recording is enabled, and applies the model's
reset.

## Synapses, delays, and STDP

Spiking synapses are current-based exponential synapses. Every connection has:

- a non-negative delivery delay;
- a positive synaptic-current time constant;
- live synaptic current and a pending event queue;
- optional bounded pair-based STDP;
- potentiation/depression amplitudes and independent trace time constants;
- explicit minimum and maximum plastic weights.

For a presynaptic spike, the post-trace depresses the weight. For a
postsynaptic spike, the pre-trace potentiates it. Coincident spikes are
processed pre then post, and every update is clamped to the connection's
weight bounds. `EnableSTDP()` can enable or disable plasticity for the complete
phenotype without changing the genome.

## Eligibility propagation learning

`EPropLearner` is an optional online temporal-credit-assignment algorithm for
supervised, reinforcement, and hybrid evolutionary workflows. It implements
eligibility propagation (e-prop) with surrogate spike derivatives and
broadcast learning signals. Unlike pair-based STDP, its third factor is a task
error or user-supplied modulatory signal, so it can train toward an explicit
temporal objective without backpropagation through time.

For each trainable synapse from neuron `i` to neuron `j`, the learner maintains
a delivered presynaptic trace `x`, voltage eligibility `epsilon_v`, and, for
adaptive neurons, adaptation eligibility `epsilon_a`. The LIF update follows
the local state Jacobian:

```text
epsilon_v <- (1 - dt/tau_mem) epsilon_v
             + (dt/tau_mem) R x
e_ji      <- surrogate(v_j - threshold_j) epsilon_v
gradient  <- gradient + L_j e_ji
```

Adaptive LIF additionally differentiates adaptation decay, the spike-triggered
increment, and adaptation current. Izhikevich targets use a bounded
membrane/recovery eligibility approximation to avoid unstable millisecond
Jacobians. Synaptic eligibility is driven by events after their configured
delay and uses the synaptic-current time constant.

The neuron learning signal is:

```text
L_j = sum_o B_jo d(loss)/d(output_o)
```

`B` can be deterministic random feedback (the default), direct symmetric
feedback from output connections, or uniform feedback. Output neurons always
receive their corresponding loss derivative directly. Available surrogate
derivatives are fast-sigmoid, triangular, and arctangent. Mean-squared and
Huber temporal losses are built in.

### Supervised Python example

```python
network.SetSpikingInputMode(neat.BINARY_SPIKE_INPUT)
network.SetSpikingOutputMode(neat.SPIKE_OUTPUT)
network.EnableSTDP(False)

config = neat.EPropConfig()
config.learning_rate = 2e-3
config.optimizer = neat.EPROP_ADAMW
config.feedback_mode = neat.EPROP_RANDOM_FEEDBACK
config.surrogate = neat.EPROP_FAST_SIGMOID
config.update_interval = 32
config.gradient_clip_norm = 1.0

learner = neat.EPropLearner(config)
learner.Initialize(network)

result = learner.TrainSequence(
    network,
    temporal_inputs,
    temporal_targets,
    time_step=0.001,
    reset_network=True,
    apply_final_update=True,
)
print(result.mean_loss)
```

`TrainStep()` advances one solver step, accumulates eligibility, calculates the
selected temporal loss, and applies an update at `update_interval`.
`TrainSequence()` handles complete aligned input/target sequences. Targets have
the same units as the selected decoder: binary values for `SPIKE_OUTPUT`, hertz
for `FILTERED_SPIKE_OUTPUT`, or voltage for
`MEMBRANE_POTENTIAL_OUTPUT`. A cumulative `FIRING_RATE_OUTPUT` can be trained
but is generally less suitable for step-local objectives.

For reinforcement learning, neuromodulation, or custom losses,
`TrainStepWithSignals()` accepts output, non-input-neuron, or full-neuron
learning signals. If simulation was advanced separately,
`AccumulateLearningSignals()` consumes signals for the latest step and
`ApplyGradients()` performs the optimizer update.

The configuration includes AdamW and SGD, global gradient clipping, decoupled
weight decay, hard weight bounds, independent input/hidden/output/recurrent
training masks, Huber delta, deterministic feedback seeding, and an update
interval. `ResetEligibility()`, `ZeroGradients()`, and `ResetOptimizer()` reset
the corresponding state independently.

The learner is separate from the phenotype, so creating one does not change
network behavior and evolution remains the default training mechanism.
Evolution can discover topology and spiking parameters, after which e-prop can
fine-tune connection weights. Topology changes require `Initialize()` again.
Simultaneous STDP is rejected by default because the two algorithms would
otherwise update the same weights; set `allow_stdp=True` only for an
intentional hybrid rule.

`EPropLearner.Serialize()`, `Deserialize()`, and Python pickle preserve
eligibility traces, fixed feedback, accumulated gradients, Adam moments,
optimizer step, and the topology signature. Save the network and learner
together for deterministic training resume.

## Input encoding and output decoding

Select an input encoder with `SetSpikingInputMode()`:

| Mode | Meaning of each input |
| --- | --- |
| `CURRENT_INPUT` | Continuous current/analog activation |
| `BINARY_SPIKE_INPUT` | A positive value emits a spike; its value is the event amplitude |
| `POISSON_RATE_INPUT` | A non-negative firing rate in hertz; sampling is exact for a Poisson process over the selected time step |

`SeedSpiking()` makes Poisson input deterministic and checkpointable.

Select an output decoder with `SetSpikingOutputMode()`:

| Mode | Output |
| --- | --- |
| `SPIKE_OUTPUT` | `0` or `1` for the current solver step |
| `FIRING_RATE_OUTPUT` | Cumulative spike count divided by simulated time |
| `FILTERED_SPIKE_OUTPUT` | Exponentially filtered instantaneous rate in hertz |
| `MEMBRANE_POTENTIAL_OUTPUT` | Current membrane state |

The same values are available directly through `OutputSpikes()`,
`OutputRates()`, `OutputFilteredSpikes()`, and
`OutputMembranePotentials()`.

## C++ example

```cpp
NEAT::NeuralNetwork network;

NEAT::Neuron input;
input.m_type = NEAT::INPUT;

NEAT::Neuron output;
output.m_type = NEAT::OUTPUT;
output.m_activation_function_type = NEAT::SPIKING_LIF;
output.m_timeconst = 0.01;
output.m_spike_threshold = 0.6;

NEAT::Connection synapse;
synapse.m_source_neuron_idx = 0;
synapse.m_target_neuron_idx = 1;
synapse.m_weight = 8.0;
synapse.m_synaptic_delay = 0.002;

network.AddNeuron(input);
network.AddNeuron(output);
network.AddConnection(synapse);
network.SetInputOutputDimensions(1, 1);
network.SetSpikingInputMode(NEAT::BINARY_SPIKE_INPUT);
network.SetSpikingOutputMode(NEAT::FILTERED_SPIKE_OUTPUT);
network.SetSpikingTimeStep(0.001);
network.Flush();

for (int step = 0; step < 100; ++step)
{
    const std::vector<double> input_spike{
        step % 20 == 0 ? 1.0 : 0.0};
    const std::vector<double> output_rate =
        network.StepSpiking(input_spike);
}
```

`SimulateSpiking()` advances an entire input sequence without repeated
language-boundary calls.

## Python evolution

`ConfigureSpiking()` is an opt-in preset. It enables a mixed distribution of
LIF, adaptive-LIF, and Izhikevich activation mutations, dedicated neuron and
synapse parameter mutation, recurrent topology evolution, and spiking-aware
compatibility distance. Passing `True` also seeds a fraction of links with
STDP.

`ConfigureMcCullochPitts(inhibitory_veto=True, enable_stdp=False)` is the
corresponding preset for canonical McCulloch-Pitts threshold neurons. See
[`MCCULLOCH_PITTS.md`](MCCULLOCH_PITTS.md) for its discrete-time rule and the
3D HyperNEAT and ES-HyperNEAT spatial API.

```python
import pymultineat as neat

params = neat.Parameters()
params.ConfigureSpiking(enable_stdp=True)
params.PopulationSize = 120
params.DontUseBiasNeuron = True

init = neat.GenomeInitStruct()
init.NumInputs = 4
init.NumHidden = 4
init.NumLayers = 1
init.NumOutputs = 2
init.SeedType = neat.LAYERED
init.HiddenActType = neat.SPIKING_ADAPTIVE_LIF
init.OutputActType = neat.SPIKING_LIF

seed = neat.Genome(params, init)
population = neat.Population(seed, params, True, 5.0, 42)

for species in population.m_Species:
    for genome in species.m_Individuals:
        network = neat.NeuralNetwork()
        genome.BuildPhenotype(network)
        network.SetSpikingInputMode(neat.POISSON_RATE_INPUT)
        network.SetSpikingOutputMode(neat.FILTERED_SPIKE_OUTPUT)
        fitness = evaluate_spiking_controller(network)
        genome.SetFitness(fitness)
        genome.SetEvaluated()
population.Epoch()
```

All ranges, probabilities, and compatibility coefficients remain individually
configurable. The dedicated mutation methods are
`Mutate_NeuronSpikingParameters()` and
`Mutate_LinkSpikingParameters()`. Structural mutation initializes new
spiking state, link splitting preserves total delay, and crossover carries
the complete state of selected genes.

## Recording and visualization

`NeuralNetwork` records timestamped `SpikeEvent` values when recording is
enabled. Use `EnableSpikeRecording(enabled, max_events)`,
`GetSpikeHistory()`, and `ClearSpikeHistory()` for direct access.

`neattools.py` adds:

- `SpikingRecorder` for aligned spikes, membrane potentials, filtered rates,
  decoded outputs, and evolving weights;
- `PlotSpikeRaster`, `PlotMembraneTraces`, and `PlotFiringRates`;
- `DrawSpikingNetwork` for live membrane, spike, delay, recurrence, and STDP
  state;
- `DrawSpatialNetwork3D` for physical neuron positions and directed axons;
- `AnimateSpikingNetwork` for a moving real-time raster, live phenotype,
  membrane traces, and a synchronized environment panel;
- `InteractiveSpikeTrains` for linked Plotly exploration;
- `spike_train_statistics` for firing rates and inter-spike intervals.

Recordings export to compressed NPZ, JSON, or tidy CSV.

## Persistence and compatibility

Genome format 4 and neural-network format 7 persist spiking gene parameters
and complete live solver state. The network checkpoint includes membrane and
adaptation state, Izhikevich recovery, refractory timers, spike counters,
rate traces, synaptic currents, pending delayed events, STDP traces, input RNG
state, recorded events, McCulloch-Pitts inhibitory state, neuron coordinates,
and physical axon lengths. Older genome and network formats remain readable.

The historical `Activate*`, `Input`, and `Output` rate-network API is
unchanged. Stateful spiking execution uses `StepSpiking()` or
`SimulateSpiking()`. RTRL remains available for differentiable rate
activations; spiking networks use evolution, optional online e-prop, and
optional STDP.
